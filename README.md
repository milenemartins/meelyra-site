# Meelyra AI

Landing page institucional da Meelyra AI — soluções de inteligência artificial sob medida para negócios.

## Estrutura

```
Meelyra-AI/
├── index.html        # Página principal
├── assets/
│   └── img/
│       └── logo.png  # Logo da marca
├── .gitignore
└── README.md
```

## Deploy

O site é um arquivo HTML estático. Pode ser publicado em qualquer serviço de hospedagem estática:

- **Vercel** — conecte o repositório e faça deploy automático
- **Netlify** — arraste a pasta ou conecte via Git
- **GitHub Pages** — ative nas configurações do repositório
